# The Quiet Page

*Lost in a book? We'll help you stay there.*

A landing page for an independent bookstore built with semantic HTML5 and CSS3. Focuses on clean design, readability, and community features. Made as a learning project for Mayerfeld Consulting Frontend Developer Practicum.

## Features

* Sticky navigation header
* Hero section with background image and CSS gradient overlay (color-mix)
* Book grids (Staff Favorites, Fiction, Non-Fiction) using CSS Grid
* Community section for book clubs and author events
* Centralized theming via CSS custom properties
* Smooth hover transitions and semantic HTML structure

## Built With

    HTML5 (Semantic tags)
    CSS3 (Flexbox, Grid, Variables, color-mix, position: sticky)
